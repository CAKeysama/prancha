De onde vêm estes números
  • Tudo vem da API pública do GitHub e é consultado de novo a cada 15 minutos, no máximo. Abrir esta página não faz uma consulta nova ao GitHub.
  • Downloads contam só os instaladores (EXE e MSI). O GitHub informa o total atual de cada arquivo, sem histórico por dia, e o mesmo computador pode baixar mais de uma vez.
  • A taxa de aprovação considera só as execuções que terminaram aprovadas ou com falha. Canceladas e puladas não entram na conta.
  • A duração vai do início ao fim da execução, como o GitHub mostra. A espera e a execução vêm do detalhe dos jobs das execuções mais recentes.
  • Esta página não usa a telemetria do aplicativo nem qualquer dado de quem usa o Prancha.
