# Prancha

- Todo PR para a `main` publica uma versão nova. Siga [CONTRIBUTING.md](CONTRIBUTING.md): commits e título do PR no formato `tipo: descrição` (`feat` sobe a minor, `!`/`BREAKING CHANGE:` sobe a major, o resto sobe a patch), `npm run version:bump`, notas no `CHANGELOG.md` e `npm run version:check` antes do push.
- Antes do merge, traga a `main` para o branch e confira de novo a verificação **Versão**: outro PR pode ter usado a mesma versão.
- Textos, commits, notas e documentação em português do Brasil.
